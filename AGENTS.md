# AGENTS.md

Two workspaces in one repo — Flutter app (`cafeteria/`) and Node.js backend (`cic-backend/`).

## Commands

### Flutter (`cafeteria/`)

```bash
flutter pub get
flutter gen-l10n          # required after editing .arb files
flutter analyze
flutter test
flutter test test/path/to/test.dart   # single test
```

### Backend (`cic-backend/`)

```bash
npm install
npm run dev              # nodemon dev server
npm run build            # tsup → dist/
npm run check            # Biome lint + format check
npm run format           # Biome auto-format
npm run lint             # Biome lint only
```

No `flutter test` or `npm test` suites exist currently — `widget_test.dart` is a stub.

## Architecture

**Flutter** — Clean Architecture, feature-driven modules under `lib/features/`. Each feature: `data/`, `domain/`, `presentation/`. Cross-cutting concerns in `lib/core/`.

**Backend** — TypeScript Express 5 + Mongoose, bundled with tsup, linted with Biome (not ESLint). Layered: `routes/` → `controllers/` → `services/` → `repositories/`.

## Key gotchas

- **Error handling is split**: `auth`/`home` use `Either<Failure, T>` (dartz). `cart`/`order`/`favourite`/`wallet` use plain `Future<T>` + throw. Match the convention of the feature you're editing.
- **Localization requires codegen**: after editing `.arb` files, run `flutter gen-l10n`.
- **Wallet domain logic** spans three service files (`order.service.ts`, `wallet.service.ts`, `userWallet.service.ts`). Orders are placed unpaid — money moves only on `delivered`/`paid` transitions. See `cic-backend/src/docs/WALLET_SYSTEM_EXPLAINED.md`.
- **DI registration**: all GetIt bindings live in `lib/features/auth/di/injaction.dart`. BLoCs are `LazySingleton`s injected at route level in `AppRouter.generateRoute()`.
- **Base URL**: `ApiConstants.baseUrl` in `lib/core/constants/`. Points to Railway in production; switch to `localhost:3001` for local backend dev.
- **`firebase_options.dart` is gitignored** — regenerated by FlutterFire CLI. Only Firebase Core is initialized; not used for data.
- **Admin vs customer routing** is determined by `user_role` in SharedPreferences (`lib/features/splash/slash.dart`).
